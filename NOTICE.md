# Attribution and licensing

This source snapshot is adapted from collaborative LLM-physics evaluation software
developed in Prof. Moritz Münchmeyer's research group at the University of
Wisconsin–Madison. Zichang (Stephen) Xu's graduate mentor is Nate Woodward.
The README describes Xu's individual contributions within that collaboration.

Existing source comments and notices in the selected files are retained. File-level
provenance and preparation changes are documented in docs/PROVENANCE.md.
New demonstration fixtures and packaging adapters were added for this portfolio;
their presence is separate from the applicant's original research contributions.

The source repository has no top-level license file in the inspected snapshot.
No new license or permission to redistribute collaborators' work is asserted by
this local preparation. Public distribution requires the appropriate rights-holder
authorization and an agreed license or publication notice.
