\subsection{Problem Statement}
For constant acceleration $a$, initial velocity $v_0$, and time $t$, find displacement.
\subsection{Answer Requirements}
Implement displacement(v0, a, t), returning a float in SI units.
\subsection{Solution}
Use $s=v_0t+\frac{1}{2}at^2$.
\subsection{Answer}
$v_0t+\frac{1}{2}at^2$
\subsection{Code}
```python
def displacement(v0, a, t):
    return v0 * t + 0.5 * a * t ** 2
```
